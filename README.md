# 📊 Excel & Power BI Portfolio

This repository showcases a selection of my work in **Excel** and **Power BI**. Each file highlights different aspects of my skills — from automation and analysis in Excel to interactive dashboards in Power BI.

## 🔧 Projects Included
### Excel
1. **Automation with Macros**  -> name project: "Automation-Avocado prices"
   - Demonstrates how repetitive tasks can be streamlined using VBA macros.  
   - Focus on efficiency and reducing manual work.

2. **Simple Analysis**  
   - A straightforward dataset analysis.  -> name project: "Analysis_avocado prices"
   - Includes basic formulas, pivot tables, and clear visualizations.  
   - Great example of clean, accessible reporting.

3. **Advanced Analysis**  -> name project: "AdvancedAnalysis_SuperStoreUS-2015"
   - Includes basic formulas, pivot tables, and clear visualizations.  
   - A more complex project involving multiple data sources and advanced functions.
  
4. **Imaginary Business Case** – Variance & Scenario Analysis
   - A fictional but realistic case study combining budget vs. actual analysis, scenario modeling, and management reporting.
   - Answers to stakeholder questions are embedded directly in the workbook.
  
5. **Budget_template simple**
   - A budget excel showing: an overview of different banks/accounts with their respective balance, a cashbook, a pivot table to examine the expenses/income
  
### Power BI 
1. ETL process with PowerBI (name: Visualization_financial instruments)
   - In this proces I picked a few financial products to visualize and analyze.
   - I used python to extract several product via an API call to Yahoo finance.
   - I performed various transformations to this data and saved this in SQL.
   - Afterwards I connected my Powerbi to this SQL database and visualized the data.
